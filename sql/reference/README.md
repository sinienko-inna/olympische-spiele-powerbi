# Musterlösung der Kursleitung

`musterloesung.sql` ist **nicht** mein Modell. Sie zeigt die vier Tabellen der Aufgabenstellung (`Athletes`, `Events`, `Countries`, `Athlete_Event`) und den `COPY`-Import.

Mein Schema weicht davon ab: Stern mit `dim_athlete` / `dim_athlete_season` und Fakt `fact_results`. Vergleich: [`docs/02-data-model.md`](../../docs/02-data-model.md).
