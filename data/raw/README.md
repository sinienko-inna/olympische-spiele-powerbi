# Rohdaten

| Datei | Inhalt | Herkunft |
| --- | --- | --- |
| `olympics_rohDaten.csv` | Eine Zeile = eine Athletenleistung in einem olympischen Event | Kursdatensatz der Fallstudie Olympische Spiele |

Spalten: `ID`, `Name`, `Sex`, `Age`, `Height`, `Weight`, `Year`, `Sport`, `Event`, `Medal`, `NOC`, `Country`.

Trenner: Tab. `Height`/`Weight` in der Datei noch unskaliert (in SQL `/ 10`).

Öffentliche Referenz derselben Datenfamilie: [Kaggle — 120 years of Olympic history](https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results).
